Notes

Two-minute how-to

  1. Run npm start and open http://127.0.0.1:4309/.
  2. Read the week desk: Monday–Sunday, America/New_York. Mark Planned or Leftover. Leftover does not order anything.
  3. Flip a Practice switch. Practice nights keep fast meals.
  4. Press Swap or Choose to change a dinner.
  5. Open Grocery and read the aisle merge.
  6. Open Fridge and press Print.
  7. On Notes, type a reminder, press Hold, then Apply.

Refused gates

These actions answer 403. Apply stores a local note and does not unlock them. Checking one does not order, check out, invent a meal, share outside this computer, or text a child. This page never reports an Instacart or auto-order success.
